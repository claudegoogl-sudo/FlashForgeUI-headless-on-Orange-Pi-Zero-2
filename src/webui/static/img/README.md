# brushed.webp

Brushed-aluminium grain used as a blended texture over the panel and button colours (see `DESIGN.md`).
Derived from "Metal 009" on ambientCG (https://ambientcg.com/a/Metal009), released under CC0 1.0 (public domain),
converted to greyscale, reduced to 256x256 and flattened in contrast. No attribution is required.
